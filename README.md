# Agent 工具调用框架

> 基于 Function Calling 的 Agent 工具编排框架：让 LLM 自主决定「什么时候调什么工具」，并处理调用过程中的各种坑。

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## 一、解决什么问题

让 LLM 调用工具不难（给个 schema 就行），**难的是这些**：

| 问题 | 后果 | 本项目的解法 |
|---|---|---|
| LLM 传错参数类型 | 工具直接崩 | JSON Schema 校验，自动类型转换 + 范围检查 |
| LLM 死循环调工具 | 成本失控 | 调用次数熔断（最多 8 次） |
| 工具返回慢 / 失败 | 整个对话卡死 | 超时控制 + 指数退避重试（2 次） |
| LLM 被诱导执行危险操作 | 删库跑路 | SQL 白名单、路径穿越检测、代码注入过滤、域名白名单 |

## 二、核心设计

```
用户提问
   ↓
LLM 决策（要调工具吗？调哪个？参数是什么？）
   ↓
┌──────────────────────────────┐
│  参数校验层                    │
│  ├─ 必填检查                  │
│  ├─ 类型转换（"5" → 5）        │
│  └─ 范围检查（min/max）        │
└──────────────────────────────┘
   ↓
┌──────────────────────────────┐
│  工具执行层                    │
│  ├─ 超时控制                  │
│  ├─ 失败重试（指数退避）        │
│  └─ 异常分类（可重试 / 不可重试）│
└──────────────────────────────┘
   ↓
结果回填给 LLM → 继续决策 or 输出答案
   ↓
（调用次数达到 8 次 → 熔断，强制停止）
```

## 三、内置的 5 类工具

| 工具 | 能力 | 安全限制 |
|---|---|---|
| `query_database` | 执行 SQL 查询 | **只允许 SELECT**，禁止多语句 |
| `read_file` / `write_file` | 读写文本文件 | 限制在 `agent_files/` 目录，**禁止路径穿越** |
| `http_get` | 发起 HTTP 请求 | **域名白名单**（httpbin / github / wttr.in） |
| `calculator` | 数学计算 | **字符白名单**，禁用 `eval` 内置函数 |
| `send_notification` | 发送站内通知 | 演示用，只记录不真发 |

## 四、快速开始

### 环境要求

- Python 3.10+
- 无需安装第三方库（纯标准库）

### 运行

```bash
# 基础用法
python agent_tools.py "数据库里有多少条用户记录"

# 显示每轮决策过程
python agent_tools.py "数据库里有多少条用户记录" --verbose

# 有 API key 时走真实 LLM
export DEEPSEEK_API_KEY="sk-xxx"
python agent_tools.py "帮我查一下订单总数"
```

### 输出示例

## 五、双模式设计

| 模式 | 触发条件 | 用途 |
|---|---|---|
| **真实 LLM** | 环境变量 `DEEPSEEK_API_KEY` 存在 | 真实场景，LLM 自主决策 |
| **本地规则** | 无 API key | 演示流程、单元测试，不花钱 |

两种模式走的是**同一套工具执行链路**，所以工具层的逻辑（校验、重试、熔断）都能验证。

## 六、安全测试结果

实测 6 类攻击场景，全部拦截：

| 攻击 | 结果 |
|---|---|
| `DROP TABLE users` | ✅ 拒绝（只允许 SELECT） |
| 缺必填参数 | ✅ 拒绝（参数校验） |
| `../../etc/passwd` | ✅ 拒绝（路径穿越检测） |
| `__import__('os').system('dir')` | ✅ 拒绝（字符白名单） |
| 调用不存在的工具 `rm_rf` | ✅ 拒绝（工具白名单） |
| 请求 `evil.com` | ✅ 拒绝（域名白名单） |

## 七、项目结构

```
.
├── agent_tools.py        # 主程序（工具注册 + 校验 + 执行 + Agent 循环）
├── agent_tools.db        # 演示用的 SQLite 数据库（自动生成）
└── agent_files/          # 文件工具的沙盒目录（自动生成）
```

## 八、已知局限

- 本地规则模式只覆盖 5 类意图，复杂指令需要真实 LLM
- 没有实现流式输出
- 工具结果是纯文本回填，没有做结构化摘要（长结果会占满 context）
